# PCBL-Core: Phase-Coherent Bit-Lattice Engine V1.0

A zero-dependency, bare-metal C++20 local foundation engine designed to bypass the memory wall of traditional data-center architectures. By replacing traditional backpropagation with forward-only **Local Phase Resonance Feedback**, it executes 2-Billion parameter continuous training passes natively inside consumer laptop CPU cache lines and unified GPU devices.

## Features
- **The Backprop Killer:** Zero memory-graph tracking. Learns via local phase coherence gates.
- **Deterministic Bitmask Encoder (DBE):** Reads string input streams byte-by-byte into high-entropy bit arrays.
- **Cross-Vendor Heterogeneous Portability:** Unified Python wrapper API orchestrating execution blocks across CPUs and GPUs from any vendor.

## Quickstart

```bash
mkdir build && cd build
cmake -G "MinGW Makefiles" ..
cmake --build .
cd ..
python pcbl.py
```
